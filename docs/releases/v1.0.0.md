# Agent Action Evals v1.0.0

**First stable release — 26 September 2026.**

Fault-injection testing for tool-using agents. Wrap existing Python functions and
LangGraph tools, inject failures, and inspect how the agent responds.

## Included in v1

- **Existing-tool wrappers:** preserve normal inputs, outputs, signatures, and
  original exceptions for synchronous and asynchronous Python functions.
- **Native LangGraph integration:** retain tool schemas, runtime injection,
  artifacts, configuration, and `Command` outputs through ToolNode's wrapper hooks.
- **Failure injection:** timeouts before execution, lost responses after a callable
  returns, and stale reads. Before/after timeouts look identical to the agent.
- **Recovery traces:** inspect attempts, repeated inputs, observations, cancellation,
  and fault coverage. Payload capture is opt-in; recovery stays with the agent.
- **Scenario testing:** reusable refund fixtures, generated fault cases, business
  state assertions, failure timelines, and JSON/JSONL/JUnit output for CI.
- **Execution adapters:** trusted in-process and subprocess execution, plus the
  documented offline Docker isolation mode.
- **Optional verification helper:** check authoritative operation receipts against
  declared effects. This API remains explicitly experimental.

## Changes since v0.3.0a1

This release promotes the tested implementation to version **1.0.0** and
establishes the [1.x public compatibility policy](https://github.com/pratik-mahalle/agent-action-evals/blob/v1.0.0/docs/COMPATIBILITY.md).
It introduces no runtime API changes from v0.3.0a1. Package metadata, installation
instructions, release documentation, and distribution artifacts use the stable version.

## Install

Requires Python 3.11 or newer. Install the wheel from this GitHub release:

```bash
python -m pip install https://github.com/pratik-mahalle/agent-action-evals/releases/download/v1.0.0/agent_action_evals-1.0.0-py3-none-any.whl
```

For examples and LangGraph support:

```bash
git clone --branch v1.0.0 --depth 1 https://github.com/pratik-mahalle/agent-action-evals.git
cd agent-action-evals
python -m pip install -e '.[langgraph]'
python examples/wrapped_sqlite_tool.py
```

The SQLite example commits one note, hides its response, and verifies the row
through a separate connection. The caller sees a timeout; the wrapper does not retry.

## Use an existing tool

Given your existing `create_issue` function:

```python
from agent_action_evals import Fault, ToolBoundary

boundary = ToolBoundary(
    (Fault("create_issue", "response_lost_after_commit", on_call=1),)
)
tested_create_issue = boundary.wrap(create_issue)
# Register tested_create_issue with your agent, run the agent, then inspect:
report = boundary.report()
```

For LangGraph, import `wrap_tool_node` from
`agent_action_evals.adapters.langgraph` and pass your existing tools and boundary.
See the [usage guide](https://github.com/pratik-mahalle/agent-action-evals/blob/v1.0.0/docs/TOOL_BOUNDARY.md).

## Validation

Publication is gated on local regression checks, fresh installation of the built
wheel, checksum verification, and the hosted CI matrix covering Linux, macOS,
Windows, Python 3.11–3.14, Docker checks, and the pinned comparison suite.
The [CI runs](https://github.com/pratik-mahalle/agent-action-evals/actions/workflows/ci.yml)
provide the recorded evidence for the release commit.

Previously recorded benchmarks are preserved with their original versions and
source hashes: synthetic verification passed 120/120 authored runs per verified
adapter; the live Jev/custom-D1 check passed 18/18 verified trials, with zero false
success claims, versus three false claims from direct tool use. This promotion
does not constitute a new model benchmark. See the
[live report and limits](https://github.com/pratik-mahalle/agent-action-evals/blob/v1.0.0/benchmarks/results/live-jev.md).

After downloading all three files, run `sha256sum -c SHA256SUMS` on Linux or
`shasum -a 256 -c SHA256SUMS` on macOS. On PowerShell, compare
`Get-FileHash <asset> -Algorithm SHA256` with its checksum entry.

## Known limits

- A callable returning does not prove that a remote effect committed. Independent
  service-state checks are required for that conclusion.
- The wrapper is trusted in-process instrumentation. Calls bypassing it and
  SDK-internal retries are outside its scope. Streaming generators need a separate
  boundary; create a fresh boundary for each run.
- LangGraph integration requires ToolNode's sync and async wrapper hooks. The
  integration has been checked with LangGraph 1.2.12 / langgraph-prebuilt 1.1.0.
- Receipt verification remains experimental, and write retries require a service's
  real idempotency guarantee. The helper cannot create that guarantee itself.
- Native service packs, an independent external-state observer integration, and
  external-team pilots remain planned work. The live benchmark used a custom
  synthetic ledger; it moved no money and tested no payment provider.

See the [roadmap](https://github.com/pratik-mahalle/agent-action-evals/blob/v1.0.0/ROADMAP.md)
for remaining validation and integration work.
